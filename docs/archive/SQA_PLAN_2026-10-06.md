# SQA Test Suite for ShikkhaHub

The test runner is already installed, but it has only a placeholder test. This plan adds real automated checks for the main parts of the app, plus a short QA guide.

## What gets tested

1. **Unit tests (logic)**
   - The Bangla/English translations: every English text has a Bangla version, and switching language works.
   - Permission rules (student/teacher/admin): each role sees only what it should.
   - Community sorting and page counting: Popular, Newest and Oldest, plus the page count.
   - Course filters read from the web address: search, category, level and sort.

2. **Component tests (screens)**
   - Header: the language toggle and dark-mode switch work, and signed-out visitors see no Leaderboard button.
   - Protected pages: signed-out visitors are sent to sign-in, and users without the right role see "access denied".
   - Sign-in page: `?tab=signup&role=teacher` opens signup with Teacher already chosen, and form checks show errors.
   - Course card, FAQ and Hero: they show data and show a fallback when data is empty.
   - The backend connection is replaced with a fake in these tests, so they never touch real data.

3. **Full-app tests in a real browser**
   - Public pages load with no errors: home, courses, community, leaderboard, sign-in and the 404 page.
   - Navbar buttons and the Paths/Live scroll links work.
   - On a phone-sized screen, the layout fits with no sideways scrolling and the mobile menu works.
   - Community paging and sorting work across pages.

4. **QA documentation**
   - A `TESTING.md` file covering how to run the tests, what they cover, and a manual test checklist (live class, video, AI assistant, grading) for things automation can't check well.

## Technical details
- Test files sit next to the code they test (`*.test.ts(x)`). Shared helpers go in `src/test/utils.tsx`: a render function that wraps screens in the router, language, theme and query providers, plus a fake backend client.
- Browser tests use Playwright, in `e2e/*.spec.ts`, against localhost:8080. A `test:e2e` command is added.
- Add a coverage report (`@vitest/coverage-v8`) and a `test:coverage` command.
- Run the whole suite and fix any real bugs it finds.
- Record the test layout in AGENTS.md.
